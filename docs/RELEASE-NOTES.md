PocketKhata 1.1 redesigns the expense and personal-loan tracker with a navy/blue/amber theme, an adaptive notebook icon, Home / Loans / Settings navigation and a fully scrolling dashboard.

The form now uses **Expense / Give a Loan / Take a Loan**. Expense records show the purpose and category; loan records show the other person's name. Phone, extra details and receipt/photo controls are grouped separately. A fixed Save button, clearer paid-back status and readable system-bar icon settings improve navigation.

**Install:** download `PocketKhata-v1.1.apk` and choose **Update** over the existing app. The signing key, package ID, Firebase structure and saved settings remain compatible. Do not uninstall to update. New users can choose Create an Account. Android 8.0 or newer.

The original v1.0 Release remains available for the course submission requirement. This release retains the original Firebase Authentication, private realtime CRUD, RecyclerView, SharedPreferences, camera/gallery and call/share/browser features.

Automated Android 12 layout/form/navigation tests, release compilation, Android lint and APK signature checks are recorded in docs/TESTING.md. The original Firebase integration passed 15 live checks. The owner's screenshots confirmed installation, signed-in records, budget display, filters and stored photos on Android 12 with v1.0; the redesigned v1.1 requires a fresh phone check. Camera and external-app actions still require confirmation on the physical phone.

Source is available in this public repository. The separate semester report remains deferred.
