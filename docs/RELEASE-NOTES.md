PocketKhata tracks daily expenses, monthly budgets, money lent and money borrowed, with private Firebase accounts and real-time sync.

**Install:** download `PocketKhata-v1.0.apk` on an Android 8.0+ phone, install it, then choose **Create an account** in the app. The APK is signed and connected to the owner's Firebase project. No default or shared password is included.

Includes Java + XML source for Android Studio, seven screens, validated CRUD, RecyclerView, camera/gallery receipts, local budget preferences, repayment status, dial/share/browser intents and a custom Material theme.

Validation: release build and APK signature verification passed; 11 automated Android/API 32 tests and 15 checks against the real Firebase backend passed; Android lint has zero errors. **Actual testing on the owner's Android 12 / ColorOS 12.1 phone is still required, especially camera/gallery and external-app actions.** See `docs/PHONE-TEST-BN.md` in the repository.

Clone or download this public repository for the Android Studio source. The separate semester report is deferred and is not included.
